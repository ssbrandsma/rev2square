# Synthetic upload-investigation fixtures

All files under `files/` are synthetic, generated by `generate.php`
(`php tests/Fixtures/Artifacts/generate.php`). No real firmware,
captures, credentials, or third-party binaries. Hostnames use
`example.com` / `.local`, addresses use documentation/private ranges,
and fake secrets are prefixed `SYNTHETIC-`. Packet checksums are
zeroed: the parsers under test do not validate checksums (stated
limitation, also true of the truncation/error handling they do test).

Regenerate any time; outputs are deterministic.

| `elf64-aarch64.elf` | AArch64 LE EXEC, same shape |

| `elf64-truncated.elf` | Cut inside the header → `truncated_header` failure |
| `not-elf.bin` | Plain text → `not_elf` (also used as not-a-capture) |

Expected highlights: entry `0x1000`; symbols `main` (defined) and
`puts` (undefined import); `DT_NEEDED libc.so.6`, `SONAME fixture.so.1`;
endpoint candidates for `https://updates.example.com/fw` and
`mqtt://broker.local:1883`.
